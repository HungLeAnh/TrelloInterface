Nạp dữ liệu bug từ file, kéo thả hoặc dán JSON
Kéo thả file bug.json vào đây (hoặc thả ở bất kỳ đâu trên trang)

File được đọc trên máy bạn. Nạp xong, các ô bên dưới được điền lại, bạn xem và sửa trước khi đăng.

Key và token Trello

File được đọc ngay trên máy bạn, không gửi đi đâu. Hỗ trợ dạng "TRELLO_API_KEY": "...", TRELLO_KEY=... hoặc JSON.

Token đọc và ghi được mọi board của bạn. Chỉ dùng file này trên máy của bạn, đừng gửi file đã lưu token cho người khác.
